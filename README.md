# OneCrosshair

Анимированные прицелы для The Elder Scrolls Online с кольцом ресурсов, щитами и индикаторами GCD, тяжёлых атак и каналов.

Автор: **oneDOK**. Версия: **1.0**. ESO API: **101051**.

## Установка

Скачайте репозиторий через **Code → Download ZIP**. Скопируйте папку `OneCrosshair` в `Documents/Elder Scrolls Online/live/AddOns/`, установите **LibAddonMenu-2.0**, включите аддон и выполните `/reloadui`.
